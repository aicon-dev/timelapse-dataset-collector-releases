# Timelapse Dataset Collector 배포본

카스웍스 타임랩스를 골라 프레임 이미지 데이터셋을 만드는 내부 도구의 배포 파일을 모아 둔 저장소입니다. 소스 코드는 들어 있지 않습니다.

- 다운로드 페이지: https://aicon-dev.github.io/timelapse-dataset-collector-releases/
- 버전별 파일: [Releases](https://github.com/aicon-dev/timelapse-dataset-collector-releases/releases)

Release는 소스 저장소의 배포 워크플로가 버전을 올릴 때마다 자동으로 만듭니다. 이 저장소에 직접 올리지 않습니다.
